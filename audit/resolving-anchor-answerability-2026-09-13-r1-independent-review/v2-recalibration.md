**Limitation, stated up front:** the original design calls for a producer applying V2 twice plus a separate producer-independent checker. A future commission should still run the intended two-pass-plus-checker structure before treating this as final admission evidence.

## Result

10 of 11 conflicted leaves resolve to the **same primary class V1 already held**, now with a reproducible, articulable rule instead of an unresolved instrument conflict — and 2 of those 10 are *refined* to pinpoint the exact defective sub-scope (specific rows/blanks) rather than flagging the whole leaf, which is strictly more useful than V1's output. 1 of 11 (`gpt_case_unsafe_assignment_01_q5`) genuinely **reclassifies** from `MISSING_REQUIRED_INFORMATION` to `ANSWERABLE_AT_BOUNDARY` once the target-freezing step is applied across the full row set — this is the recalibration doing its job, not a forced match to V1.

## Spot-check: did V2 destabilize any previously-clean leaf?

Sampled 6 of the 30 non-conflicted leaves (stratified across parents and classes) and re-applied V2's tests: `..._cloze_priority` (ANSWERABLE), `..._abg_indication` (ANSWERABLE, GINA threshold application), `opus3_iv_potassium_safety_case_01_q2` (CONTENT_SHARED_SURFACE_REPAIR_REQUIRED — confirmed, the missing order concentration/route/rate is the actual driver, not merely the summary's "unsafe" label), `preeclampsia_initial_priority_mc` (ANSWERABLE, anticipatory-care general knowledge), `gpt_r1_regen_case_celiac_01_q2` (ANSWER_SPACE_OR_KEY_DEFECT — the B12=280 "normal" claim without a stated reference interval, which **independently cross-validates the Matrix lane's `MX-118` finding on the same case**, now confirmed twice by two separate audit lanes), `..._part_5_support_limited_reassessment` (ANSWER_SPACE_OR_KEY_DEFECT, key/rationale mismatch). None flipped. No new instability introduced.

## Conclusion

V2's rules are workable: applied to the exact 11 leaves they were designed to fix, they produce a single, defensible, reproducible class for every one — no leaf remained stuck in an unresolved "both readings plausible, record both" state — while leaving the 6 spot-checked clean leaves undisturbed. This satisfies the content bar I set in the original method review. The remaining gap is structural, not substantive: this was a single-seat re-derivation, not the two-pass-producer-plus-independent-checker structure the design calls for. A future commission should still run that fuller structure, ideally on a fresh contrast set (the bounded ≤4-parent/≤12-leaf set the combined-instrument spec already names) rather than only the same 8 parents, before fully admitting the 441-leaf expansion.
