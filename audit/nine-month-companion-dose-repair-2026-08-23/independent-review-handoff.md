## Source adjudication

The current [AAP acetaminophen dosing page](https://www.healthychildren.org/English/safety-prevention/at-home/medication-safety/Pages/Acetaminophen-for-Fever-and-Pain.aspx),
updated 2026-01-30, says to use the child's weight to select the amount and links the current
[print-friendly AAP dosing chart](https://downloads.aap.org/HC/EN/Acetaminophen_Pictographic_Dosing_Chart_download.pdf).
That chart maps:

- 18–23 lb (8–10 kg)
- infants' acetaminophen 160 mg/5 mL
- 3.75 mL

Liam's documented 8.9 kg converts to about 19.62 lb and falls inside both printed boundaries. The
case's rounded “about 19.6 lb” value is internally consistent. No source evidence supports changing
his weight merely to retain the old answer. The repair therefore preserves 8.9 kg/about 19.6 lb and
changes the taught clinic/package-table dose from 5 mL to 3.75 mL.

The AAP page also states that acetaminophen should not be given to children under 2 without clinician
guidance. This case occurs during a pediatric visit and explicitly presents a clinic dosing table; the
repair does not convert the table into unsupervised dosing advice. The existing AAP
[liquid-medicine guidance](https://www.healthychildren.org/English/safety-prevention/at-home/medication-safety/Pages/Using-Liquid-Medicines.aspx)
supports using an appropriately marked device, preferably an oral syringe, following the stated amount
exactly, and using caregiver return demonstration.

The product concentration `160 mg/5 mL` is not the erroneous dose and remains unchanged. Danielle's
reported 1 tablespoon/15 mL administration is the unsafe exposure history and also remains unchanged.
