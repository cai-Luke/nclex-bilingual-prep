## 1. What exact bytes/fields were reviewers supposed to compare?

Per the spec, reviewers judged **pairs of items** for two primary categories: **DC** (direct contradiction — two items teach incompatible rules) and **AK** (answer-key conflict — same scenario, divergent keyed answer), plus ride-along categories **RI** (internal inconsistency within a single item already in the slice), **SC** (stem cueing), and **BD** (bilingual divergence). Every DC/AK finding required a "quotation rule": verbatim spans from *both* IDs. RI is explicitly a single-item, self-consistency check (key vs. rationale within one item) — the same class of defect present in Item B q1.

## 3. Could a key/rationale inversion in one embedded matrix child evade the workflow even if pair-level prose sounded coherent?

Yes, and the routing/manifest trail shows this specific evasion happened. `audit/early-bank-semantic/layer-a-queue.jsonl` shows Layer A's deterministic routing **did** flag the child item itself for coherence review, at the correct path: `{"id":"gpt_gap_2026_06_12_nonmcq_balanced_case_pressure_injury_nutrition_03_q1", ..., "path":"questions[244].caseStudy.questions[0]", "track":"coherence", "pair_with":["gemini_b9_05","gpt_case_premium_next_case_rehab_pressure_bowel_02_matrix_risk"], "routing_reasons":["topic/answer similarity pair","redundancy cluster size >= 3"]}`.

However, **no manifest row in any lane** (`gemini.manifest.jsonl`, `claude.manifest.jsonl`, `claude.phaseB.manifest.jsonl`, `codex.manifest.jsonl`, `codex.phaseB.manifest.jsonl`) ever adjudicates this q1-vs-`gemini_b9_05` pairing — a targeted search for `gemini_b9_05` across every coherence-lane artifact returns zero hits outside the routing queue itself. `CAMPAIGN-STATUS.md` confirms the June 24/25 Phase A coherence pilot covered "109 unique items / 156 candidate pairs" against a Layer A baseline of "1,136 unique queued IDs" — i.e., the pilot was an explicit sample, not exhaustive coverage of the routing queue. The only adjudications that *did* occur for anything touching this item operated one level up, at the parent case-study container, comparing whole-case clinical themes (staging, offloading, delegation) — never opening or citing the embedded q1 matrix's own `matrix.columns`/`correct`/`rationale.byChoice`. So yes: a case-level pairing can be judged "clinically consistent" using real evidence about the parent case, while an embedded child's own internal key/rationale inversion goes completely unexamined, and separately, the specific child-level routing that *would* have caught it was queued but never actually reviewed within the pilot's sampled scope.

## 4. Was there a deterministic check in June that would have forced detection?

No. Nothing in `validate-bank`/schema validation cross-checks `matrix.correct[].columnIds` against the semantic direction of `rationale.byChoice` prose — that comparison requires clinical/semantic judgment, not structural validation, and schema conformance does not encode it. Detection depended entirely on an LLM reviewer opening the specific item and reading `correct` against `byChoice`. The **RI** category is capable of catching exactly this defect class when applied at the item level — proven by an unrelated same-lane example: `claude.manifest.jsonl` contains one RI finding, `findingRef: CONCERN #1`, on `gemini_c9_01`, verdict FIX, where a rationale summary sentence named the wrong option letter while the keyed answer and per-choice rationale were correct — a genuine internal-inconsistency catch, with verbatim evidence cited both ways, showing the mechanism works when actually invoked. But RI is a "ride-along" category applied only "on any item already in the slice" during LLM review, is not automated, and (per §3.6.3) this particular item was never actually opened by a reviewer within the sampled pilot's scope. So: capable-in-principle, LLM-judgment-based, non-deterministic, and — for this specific item — not exercised at all.

## Summary judgment for this section

Verified workflow behavior (not inference): (a) Layer A routing correctly identified this exact item as a coherence-review candidate; (b) the sampled Phase A/B pilot did not cover every routed pair, and this pairing's manifest is entirely absent from all lanes; (c) the case-level pairings that *were* reviewed used real evidence in the Claude lane but templated non-specific text in the Gemini lane, and in both cases operated one container level above the actual defect. Inference (not directly verified, but consistent with all observed evidence): the reviewers who filed the case-level DISMISS verdicts did not open the embedded q1 matrix at all, since none of their `finding`/`evidence` text references `matrix.columns`, `correct`, or `rationale.byChoice` for the child item.
